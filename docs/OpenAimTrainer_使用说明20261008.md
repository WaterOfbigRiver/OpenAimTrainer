## 1. 快速上手

### 1.1 三种运行方式

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 桌面端（推荐） | 双击项目根目录的 `启动游戏.bat` | 直接用 Godot 运行本项目，无需打包 |
| 编辑器 | 双击 `打开编辑器.bat` | 打开 Godot 编辑器，按 F5 运行 |
| Web 版 | 用 Godot 导出 Web 后打开 `web/index.html` | 功能一致，但**没有**渲染缩放、窗口模式与「退出」按钮，鼠标灵敏度另带 0.6786 系数（见 3.2） |

### 1.2 第一次玩的推荐顺序

1. 首页 **Game** 下拉框选中你常玩的游戏（无畏契约 / 反恐精英 / 堡垒之夜）。
2. 在 **灵敏度** 输入框里填写**你在该游戏里真实使用的数值**（默认 0.215 是 Valorant 档位）。
3. 点 **设置** 把准星调成自己习惯的样子（颜色、粗细、中心点）。
4. 回到首页点 **开始训练**，或直接在右侧模式列表里点某个模式。
5. 训练中鼠标必须处于捕获态；如果弹出提示，点一下提示按钮即可继续。
6. 60 秒结束后看结算，点 **重新开始** 再练一轮。

## 3. 首页设置详解

### 3.1 3D / 2D 开关（CheckButton「3D」）

- **勾选（默认）**：右侧列出 4 个 3D 模式，显示灵敏度与渲染缩放。
- **取消勾选**：右侧列出 3 个 2D 模式；灵敏度、设置按钮与渲染缩放会隐藏（2D 不使用鼠标灵敏度，用的是屏幕绝对坐标点击）。
- 该选择会被记住，下次启动自动恢复。

### 3.2 游戏（Game）与灵敏度（Sensitivity）

这是本项目最核心的设置：**让训练器里的鼠标速度和你在真实游戏里保持一致**，否则练的是错误手感。

实际转速公式（`scripts/characters/CharacterBody3D.gd`）：

```52:52:scripts/characters/CharacterBody3D.gd
		mouse_sensitivity = user_sensitivity * conversion_sensitivity
```

- `user_sensitivity`：你在输入框里填的数。
- `conversion_sensitivity`：由所选游戏决定（`scripts/global.gd` 的 `games_sensitivities`）。
- 单位是 **度 / 像素**：鼠标横移 1000px 对应的转身角度 ≈ 数值 × 1000。

| 游戏（下拉框显示名） | 换算系数 | 常见取值区间 | 备注 |
| --- | --- | --- | --- |
| 无畏契约 Valorant | 0.0707589285714285 | **0.15 – 0.8**（多数人 0.25–0.5） | 默认 0.215 就是这一档 |
| 反恐精英 (CS) CounterStrike | 0.0222372497081799 | **0.5 – 2.5** | CS 值 ≈ Valorant 值 × 3.18 |
| 堡垒之夜 Fortnite | 0.00561534231977053 | **3 – 10** | ≈ Valorant 值 × 12.6 |

参考手感：Valorant 0.215 → 约 15°/1000px；Valorant 0.5 → 约 35°/1000px；CS 2.5 → 约 56°/1000px。超过约 60°/1000px 基本做不了静态点击，低于 5°/1000px 转身会很吃力。

要点：

- **没有「越高越好」**：值高转向快但准星容易飘，值低更稳但跟不上快速移动靶。建议调到「能稳定 180° 转身且不过冲」。
- **输入会自动校验**：空串、字母、中文全角标点（如 `0，5` 会自动按 `0.5` 处理）等非法输入会**保留上一次有效值**，不会再被写成 0；灵敏度另夹在 `0.001 ~ 1000`（历史上填 0 会变成"视角完全不动"，该问题已修复，且启动时若发现存档为 0 会自动恢复默认 `1.0`）。
- **填负数仍会左右上下反向**，属预期行为，不是 bug。
- **Web 端额外乘 0.6786**（浏览器鼠标采样补偿，不是 bug），同样数值下比桌面端慢约 1/3。
- **改完要重新开始一次训练才生效**（灵敏度在 `CharacterBody3D._ready()` 里读取）。
- 下拉框的显示名跟随界面语言，内部 key 不变，所以切换语言不会影响已保存的换算系数。

### 3.3 渲染缩放（滑条）

- 范围 **0.5 – 2.0**，步进 **0.25**（共 7 档），默认 **1.0（100%）**。
- 改的是 **3D 画面渲染分辨率倍率**（`scaling_3d_scale`），**不是窗口大小**。
- 效果：调高画面更清晰、更吃显卡；调低可显著提升帧率（竞技类训练建议优先保帧率）。
- 标签实时显示 `渲染缩放：宽 × 高 (百分比)`，右侧还有 `100%` 数值标签。
- 仅在 3D 模式与桌面端显示（2D 与 Web 版隐藏）。

### 3.4 模式列表

- 每行 = 预览小窗 + 模式按钮；所有按钮**等宽**（按最宽文字再放宽 10%），列表总高与左列对齐。
- 点按钮直接进入该模式；3D 模式会先捕获鼠标。

### 3.5 开始训练 / 设置 / 退出

- **开始训练**：在当前维度（3D 或 2D）里**随机**抽一个模式开始。
- **设置**：进入 Options 设置页。
- **退出**：退出程序（Web 版隐藏）。

## 4. 设置页（Options）逐项说明

### 4.1 准星（CROSSHAIR）

| 项 | 默认值 | 作用与调节建议 |
| --- | --- | --- |
| **Crosshair（准星总开关）** | 开 | 关掉后画面上只剩中心点（若 Dot 也关则完全没有准星）。 |
| **Outline（描边）** | 开 | 给准星各条臂加一圈描边，在亮色背景下更清楚；描边颜色见下。 |
| **Crosshair inner（内臂）** | 开 | 四条靠近中心的短臂。关掉后只剩中心点（适合极简点式准星）。 |
| **Dot（中心点）** | 关 | 中心正方形小点，静态点击玩家常用。 |
| **DotSize（点径）** | 6 | 中心点的半边长（像素）。2–4 精细，6–10 醒目。 |
| **OutlineSize（描边粗细）** | 2 | 描边线宽。1 细腻，3–4 在杂乱背景里更清楚。 |
| **CrosshairHeight（准星臂粗）** | 4 | 每条臂的**半厚度**，4 表示臂总厚 8px。数值越大臂越粗。 |
| **CrosshairWidth（准星臂长）** | 12 | 每条臂从间隙外缘向外延伸的长度。越大越张开。 |
| **CrosshairSpace（中心间隙）** | 5 | 中心留空的半径。0 时四条臂在中心闭合；数值越大越像「空心十字」。 |
| **CrosshairColor（准星颜色）** | 青色 `#00FFFF` | 准星主体颜色，建议与场景背景高对比。 |
| **OutlineColor（描边颜色）** | 黑色 `#000000` | 描边颜色，浅色背景用黑、深色背景可用白。 |

> 几何关系（见 `scripts/ui/Crosshair.gd`）：臂的内端距中心 `Space`，外端距中心 `Space + Width`，横向半厚 `Height`；中心点边长 `2 × DotSize`。

### 4.2 目标（TARGET）

| 项 | 默认值 | 作用 |
| --- | --- | --- |
| **TargetColor（目标颜色）** | 黄色 `#FFFF00` | 同时作用于 **3D 靶子**（材质 albedo）与 **2D 靶子**（modulate）。改完下一局生效。 |

### 4.3 界面与显示

| 项 | 默认值 | 作用 |
| --- | --- | --- |
| **Language（语言）** | 跟随系统，缺省英文 | 共 **15 种**：English、Español、简体中文、繁體中文（台灣）、繁體中文（香港）、日本語、한국어、Français、Deutsch、Português (Brasil)、Русский、Italiano、Türkçe、العربية、Tiếng Việt。切换后会立即重载界面（含模式名与游戏名）。系统 locale 的智能匹配：中文按地区细分（TW/HK → 对应繁体，其余 → 简体），`pt` / `de_DE` / `es_419` 等变体也会落到对应语言。 |
| **Display（显示模式）** | 全屏 | 窗口 / 最大化 / 全屏。训练中不再强制全屏，只要鼠标处于捕获态即可。 |
| **Window size（窗口大小）** | 1600 × 900 | 四档：1280×720 / 1600×900 / 1920×1080 / 2560×1440。**选择具体尺寸会自动切到窗口模式**；尺寸超过屏幕可用区域时会按屏幕自动收敛并居中。 |

> 提示文案：设置页底部与首页都支持 **F 键**在窗口 / 全屏之间切换（焦点在输入框时不触发）。

### 4.4 导入 / 导出（IMPORT / EXPORT SETTINGS）

| 按钮 | 作用 |
| --- | --- |
| **Export（导出）** | 桌面端弹出保存对话框，把全部设置导出为 `open_aim_trainer.json`；Web 端直接触发浏览器下载。 |
| **Import（导入）** | 选择（Web 端为上传）一个 JSON 配置文件，整体覆盖当前设置并立即落盘。 |
| **Back（返回）** | 回到首页。 |

## 5. 玩法详解（7 种训练模式）

所有模式统一为 **60 秒一局**。配置集中在 `scripts/global.gd` 的 `models3d` / `models2d`。

### 5.1 3D 模式（4 种）

**通用规则**

- 第一人称：鼠标转视角，`WASD` 移动，`空格` 跳跃，鼠标左键射击。
- 靶子生成在 Z = −25 的平面上，命中一枪即碎（靶子 10 血、子弹 10 伤害），**击碎后立刻补一个新靶**，场上数量恒定。
- 新靶生成时会与已有靶保持最小间距（`size × 2 + 1`），避免重叠 / 穿模。
- 移动靶碰到靶笼边界会反弹；靶笼尺寸按当前模式的生成范围自动调整。
- **命中率 = 命中数 / 开枪数**；移动中开枪会有扩散，最大 ±2°（速度越快越明显），静止射击最准。

| 模式名（中文） | 内部 key | 初始靶数 | 靶尺寸 | 生成范围 X / Y | 是否移动 | 训练侧重点 |
| --- | --- | --- | --- | --- | --- | --- |
| 3D 头部高度靶 | `3D_HEAD_LEVEL_V1` | 1 | 0.5 | ±24 / 固定 4 | 否 | **头部线预瞄**：靶子始终在同一高度，练横向拉枪与开枪节奏 |
| 3D 多目标 · 移动（小） | `3D_MULTIPLE_BASIC_TARGETS_MOVEMENT_V1` | 6 | 0.5 | ±12 / 4–20 | **是** | **动态目标切换 + 跟枪**：6 个小移动靶，练目标切换与追踪 |
| 3D 多目标 · 静止（小） | `3D_MULTIPLE_BASIC_TARGETS_V1` | 6 | 0.5 | ±12 / 4–20 | 否 | **静态点击（小靶）**：小靶精确定位，练微定位与手速 |
| 3D 多目标 · 中型（大） | `3D_MULTIPLE_MEDIUM_TARGETS_V1` | 3 | 3 | ±11 / 4–15 | 否 | **近距离大目标快速击杀**：靶大好打，练极限速度与连贯性 |

> 想冲分数就打「中型（大）」，想练精度就打「静止（小）」，练跟枪打「移动（小）」，热身用「头部高度靶」。

### 5.2 2D 模式（3 种）

**通用规则**

- 鼠标点击屏幕上的圆形靶子，点中即得分并立即补一个新靶，场上数量恒定。
- 不使用游戏灵敏度（屏幕绝对坐标点击），靶子尺寸与生成边距按 **1920 宽为基准等比放大**，高分屏上不会过小。
- 移动靶碰到容器边界反弹。

| 模式名（中文） | 内部 key | 初始靶数 | 靶尺寸 | 边距 | 是否移动 | 训练侧重点 |
| --- | --- | --- | --- | --- | --- | --- |
| 2D 网格速点 | `2D_GRIDSHOT_V1` | 3 | 60 px | 100 | 否 | **经典 Gridshot**：三个较大靶，练大范围快速定位与点击节奏 |
| 2D 反应点击 | `2D_REFLEX_V1` | 1 | 40 px | 100 | 否 | **反应速度**：同屏只有一个小靶，出现即点，练反应与首次定位 |
| 2D 移动追踪 | `2D_MOVING_TARGETS_V1` | 5 | 40 px | 100 | **是** | **追踪与预判**：5 个小靶同时移动，练平滑跟手与提前量 |

## 6. 计分、结算与历史最佳

| 维度 | 结算内容 | 展示文本 |
| --- | --- | --- |
| 3D | 击杀数、**命中率（%）**、历史最佳击杀 | `N 次击杀 · 模式 ｜ 命中率 X% ｜ 最佳 M` |
| 2D | 得分、历史最佳得分 | `得分：N ｜ 最佳：M` |

- 成绩按**模式**分别记录（`DataManager` 的 `records` 键，结构 `{模式: {best_score, best_accuracy}}`），只在刷新纪录时更新。
- 结算面板里：**重新开始**（原地重开同一模式）、**主菜单**（回到首页）；本轮结束后「继续」会被隐藏，焦点自动给到「重新开始」，键盘也能直接操作。
- 60 秒到点自动结算；窗口失焦会自动暂停，避免切窗丢时间。

## 8. 存档、导入导出与常见问题

### 8.1 存档位置

所有设置写入 JSON 文件：

| 平台 | 路径 |
| --- | --- |
| Windows | `%APPDATA%\Godot\app_userdata\Open Aim Trainer\open_aim_trainer.json` |
| 其他 | `user://open_aim_trainer.json`（Godot 用户数据目录） |
| Web | 浏览器本地存储 + 手动导出/导入 JSON |

主要字段：`locale`、`display_mode`、`window_size`、`sensitivity`、`sensitivity_game`、`sensitivity_game_value`、`resolution`、`is_3d_mode`、`records`，以及 `Crosshair` / `Outline` / `CrosshairInner` / `Dot` / `DotSize` / `OutlineSize` / `CrosshairHeight` / `CrosshairWidth` / `CrosshairSpace` / `CrosshairColor` / `OutlineColor` / `TargetColor`。

> `sensitivity_game_value` 存的是换算系数本身，所以升级版本或切换语言都不会让旧存档失效。

> **导入 / 读取保护**：只有能解析成合法 JSON 对象的内容才会被应用；解析失败（文件损坏、选错文件、内容为数组或纯数字）时**保留现有设置**，仅在控制台输出警告。启动时若发现存档损坏，会先把它备份为 `open_aim_trainer.json.bak`（已有备份则不覆盖），再用默认设置继续运行。

### 8.2 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 进 3D 训练后视角不动 / 提示需要捕获鼠标 | 3D 需要鼠标捕获态；点一下提示按钮即可（会同时应用当前显示模式并捕获鼠标），或直接按 Esc 再继续 |
| 改了灵敏度没变化 | 灵敏度在关卡初始化时读取，**需要重新开始一局** |
| 2D 模式下看不到灵敏度和设置按钮 | 设计如此：2D 用屏幕绝对坐标点击，不参与灵敏度换算 |
| Web 版感觉鼠标更快 / 更慢 | Web 端额外乘 0.6786 做浏览器采样补偿，属预期行为 |
| Web 版没有渲染缩放和退出按钮 | Web 环境不支持，已主动隐藏 |
| 切换语言后界面没变 | 会重载当前场景；若处于训练中，请回主菜单再切换 |
| 语言下拉框显示的语言和实际不一致 | 已按生效 locale 反查选中项（含 `zh_TW` / `zh_HK` / `pt` / `de_DE` 等变体匹配），如仍异常可导出配置检查 `locale` 字段 |
| 帧率不够 | 把渲染缩放调到 0.5–0.75；或改用窗口模式并降低窗口尺寸 |
| 靶子叠在一起 | 已内置最小间距与靶笼自适应；极端情况（如改过模式参数）可重开一局 |
| 想把设置搬到另一台机器 | 设置页 Export 导出 JSON → 另一台机器 Import 导入 |
| 导入 JSON 后设置没变化 | 说明该文件不是合法的设置 JSON（损坏或选错文件）。现在会**拒绝应用**并保留原设置，控制台输出 `导入内容不是合法的设置 JSON` 警告；请确认选的是 Export 导出的文件 |
| 设置莫名回到默认 | 存档损坏或被清空。启动时会把损坏文件备份为 `open_aim_trainer.json.bak`，可手动检查或从备份恢复 |

## 9. 开发者指南（翻译 / 构建 / 冒烟）

### 9.1 翻译表维护

- 源表：`assets/text/translations.csv`，**首行**为 `key,<locale>...`（现为 15 个 locale 列），第一列为翻译键。
- 编译产物：`assets/text/translations.<locale>.translation`，并需在 `project.godot → locale/translations` 与 `translations.csv.import` 的 `dest_files` 中登记。
- **推荐方式（Godot 自带导入器，自动按 CSV 列生成）**：

```powershell
godot --headless --path . --import
```

- 备选方式（自写脚本，自动从 CSV 表头读取所有 locale）：

```powershell
godot --headless --path . --script res://tools/build_translations.gd
```

### 9.2 常用校验命令

```powershell
# 无头冒烟（无脚本报错即通过）
godot --headless --path . --quit-after 200

# 新增 / 修改 CSV 后重新生成翻译资源
godot --headless --path . --import
```
